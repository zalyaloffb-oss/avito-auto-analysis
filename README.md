# Автоанализ

## Поиск на портале

На компьютере должны быть установлены Node.js и Google Chrome. В папке проекта установите зависимости командой `npm install`, затем запустите `Запустить портал.cmd`. Откроется локальный портал `http://127.0.0.1:39271/`. Укажите марку, модель и нужные параметры, нажмите «Найти объявления». Результаты появляются на этой же странице. Кнопка «Войти в Авито» открывает отдельное окно Chrome для самостоятельного входа; если Авито запросит проверку, выполните её сами и повторите поиск. Пароль не вводится на портале.

Марка и модель передаются как текст поискового запроса Авито, цена — как параметр поисковой страницы. Код региона берётся из URL Авито, например `kazan` или `moskva`; пустое поле — вся Россия. Год, поколение и пробег проверяются после получения карточек, а объявления с нераспознанным требуемым параметром исключаются. Авито может ограничить выдачу или изменить разметку; сборщик ещё не проверен на реальной выдаче. Запрос обрабатывает до трёх страниц и максимум 30 объявлений.

Опубликованная версия GitHub Pages остаётся статической: для запуска поиска нужен локальный портал. Локальный помощник принимает запросы только с собственной страницы и не публикует ваш браузерный профиль. Сбор выполняется вручную по нажатию кнопки, результаты остаются в браузере до обновления страницы. Импорт JSON сохранён.

## Прежний сборщик

`Запустить сбор.cmd` запускает прежний консольный сценарий с ручной настройкой поиска на Авито и сохранением `avito-results.json`. Профиль и результаты исключены из Git.
