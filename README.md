# Автоанализ

Статическая страница `index.html` отображает и фильтрует данные. Локальный сборщик `collector.cjs` открывает отдельный профиль Chrome: войдите в Авито самостоятельно, выберите категорию «Автомобили» и настройте фильтры. По нажатию Enter в окне сборщика он прочитает выдачу и страницы объявлений и сохранит `avito-results.json`. Откройте его кнопкой «Загрузить JSON» на сайте.

Для запуска нужны Node.js, Google Chrome и зависимости (`npm install`). Запуск: `node collector.cjs` или `Запустить сбор.cmd`. Сборщик не вводит пароль и не обходит проверки. Профиль и результаты исключены из Git. На GitHub Pages серверный сборщик не запускается, поэтому его нужно запускать на своём компьютере.

Селекторы и названия характеристик зависят от разметки Авито. Если поле не распознано, оно остаётся пустым. Проверка работоспособности на реальной выдаче обязательна; поля и полнота не гарантированы.

Списки марки, модели и поколения на сайте формируются из полей `make`, `model`, `generation` загруженных данных; поле `year` содержит год выпуска. Это фильтры уже собранных объявлений, исходные параметры поиска выбираются на Авито. Если характеристика не распознана, она остаётся пустой.
